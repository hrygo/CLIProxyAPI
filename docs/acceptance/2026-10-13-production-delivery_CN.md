## 实验设施与生产分离

完整分页读取确认，原 PR #25 有 225 个变更路径，其中 86 个 `ops/tool-loading` 文件包含实验客户端适配、任务库、统计、观测及验收 runner，CI 另增加了该 Python 设施门禁。

这 86 个文件已移出本地生产候选，CI 恢复到 PR 的 `main` 基线 `4ae95c2f`；生产源码、协议回归、已有维护检查与服务器构建保留。原工作区仍有全部 86 个文件及后续未提交实验；`7f495158` 保留分离前的完整提交，远端历史[快照](https://github.com/hrygo/CLIProxyAPI/tree/d9e64b8eff81414244703220d44d651d195ee428/ops/tool-loading)仍可追溯。分离不删除历史结果或用户的原工作区数据。

`internal`、`sdk`、`cmd`、`test` 和 `config.example.yaml` 与 `7f495158` 字节内容相同。测试包数减少两个来自移出的实验 Gateway package。历史报告和原方案保留并标明适用时点；旧设施和固定统计门槛不再是修复交付前置。范围核对回执与验证日志在本机原工作区 `.omo/tool-loading-completion/t33-*`。
