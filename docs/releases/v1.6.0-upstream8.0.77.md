# v1.6.0-upstream8.0.77 - 2026-11-18

## Summary

- Brings the fork to the complete upstream v8.0.77 release while preserving strict Codex tool arguments, Responses tool discovery and schema flattening, tool identity checks, and the opt-in first-frame timeout.
- Authentication, credentials, and configuration keep their existing formats. Review the embedded Codex catalog if a client relies on the GPT-5.5 priority service-tier option.

## Upstream alignment

- Upstream release: `v8.0.77`
- Previous baseline: `v8.0.57`
- Intake record: [absorbed.md](../../ops/upstream-intake/absorbed.md)
- Ported: 197 upstream commits, including 169 non-merge commits, as a complete-tree replay of upstream commit `a5e8f69e`. The [replay review](../../ops/upstream-intake/reviews/v8.0.77-replay.md) records the fork capability decisions.
- Skipped: Upstream-only CI workflows, the floating catalog refresh script, and promotional content excluded by the fork's release and governance policy.

## Breaking changes

- No configuration, credential, or storage migration is required. The embedded upstream GPT-5.5 catalog entry has an empty `service_tiers` list, so clients using that bundled catalog no longer see its priority option.

## Added

- The embedded Codex catalog lists GPT-6.2 Astra and Sol. Model availability still depends on provider credentials and routing.
- Compatible Responses routes can perform local compaction. Payload replacement rules now support regular expressions, system and developer messages, and path targets.

## Changed

- Codex ToolSearch keeps the prompt-cache prefix when loading deferred tools.
- Request logging separates local failures from upstream response data. Fork-specific request preparation and outbound validation remain active.

## Fixed

- Codex WebSocket overload and inferred-status errors preserve applicable `Retry-After` headers.
- Devin fails over on empty upstream completions and avoids synthesizing successful completion after cancellation.
- Error-only Antigravity stream logging no longer falls back to a recycled Gin context when there is no request-owned sink.

## Security

- The replay retains the fork's credential boundaries and outbound tool validation. No credential migration is needed.

## Validation

- The macOS arm64 replay passed the full fork gate with Go 1.26.10, including the hook inventory, full suite, race-sensitive packages, and server build. The new logging race regression passed 20 focused repetitions.
- Paired local binaries passed Chat Completions, Messages, Codex and Meta Responses, and OpenAI-compatible deferred tool search with scripted upstreams. There were 634 passing focused tests and subtests. Live provider inference and production restart were outside this validation.

## Known issues

- Pristine upstream v8.0.77 reproduces the GPT-5.5 service-tier test mismatch and a test-only pluginhost copied-lock `go vet` diagnostic. The gate records those two upstream exceptions.
- The standalone Claude web-search-router and Codex service-tier plugin examples require module metadata updates in pristine upstream v8.0.77. The server build and protocol replay do not use those examples.
