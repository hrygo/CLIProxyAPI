## Changed

- Meta subscription telemetry is filtered from downstream responses, SSE and WebSocket forwarding while normal output, usage and completion handling remain with the fork pipeline.
- Claude explicit per-minute limits with a short Retry-After use the narrow cooldown; HTTP status errors retain precedence over textual transport-error classification.

## Fixed

- Shorten overlong Codex call IDs without losing output associations or colliding with existing IDs; preserve exact wrapped MCP tool names and unique Gemini-to-Claude tool-use IDs.
- Remove mathematically integral schema bounds outside int64 while preserving valid fractional bounds, schema literals and exact limits.
- Normalize Gemini media function-response boundaries and remove replayed trailing thought-only turns before Vertex payload overrides, retaining the existing post-rule boundary normalization.
- Correct cache-aware Antigravity token accounting and Devin stream estimates; omit absent tool_calls fields and ignore invalid/null Claude cache controls.
- Honor complete Vertex publisher/version prefixes for execution, streaming and token counting, and omit unsupported xAI web_search options.
- Recover expired Antigravity negative-credit hints, preserve plugin auth identity with relative configured paths, and use active Devin/Meta model getters with credential-quota availability handling.
- Treat closed HTTP/2 connections as transient lifecycle failures without penalizing healthy credentials.

## Security

- Hash management secrets before newly seeded Git/object/SQL configuration persistence. Invalid YAML or aliases retaining plaintext refuse the seed. This protects newly seeded configurations; it does not rewrite previously published remote history or rotate secrets.
- Escape request paths in access logs to prevent injected line breaks. Existing authentication, authorization and listener policies remain unchanged.
