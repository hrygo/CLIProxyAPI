# v1.2.0-upstream8.0.16 - 2026-10-09

## Summary

- Absorb deferred upstream v8.0.13 maintenance work and selective upstream v8.0.16 fixes on top of v1.1.2.
- Restore Claude 4.6 model definitions (operator-confirmed still live on Antigravity) and add Claude 5.5 CAQS thinking-signature replay support.
- Complete the upstream websocket-disconnect propagation port for xAI connections so a stale terminal error cannot leak across retry dials.
- No configuration migration, module-path change, or deprecated management-endpoint change.

## Breaking changes

- None.

## Added

- Client/shared upstream configuration with historical aliases, comment-preserving updates, and old SDK source compatibility (from deferred v8.0.13).
- Transient v8 credential indexes for management config, with isolated plugin OAuth sessions across repeated runs.
- Debug connection tracing and plugin cooldown-reset callback.
- Action sources in Claude web search translation and URL-citation preservation in OpenAI response translation (upstream v8.0.16).
- Claude 5.5 CAQS thinking-signature replay support with ambiguous-wrapper rejection and per-account model entitlement refresh.
- Claude 4.6 model definitions (`claude-opus-4-6-thinking`, `claude-sonnet-4-6`), restored after operator confirmation that 4.6 remains live on Antigravity.

## Changed

- Shared settings now apply to API keys; OAuth-only headers keep their scope.
- AI Studio buffered response completion and error handling now keep DONE-tail translation on the original request.
- Websocket session activation propagates upstream disconnect errors; xAI connections reset the recorded terminal error on each new connection, matching Codex behavior.
- OAuth tool aliases are shared across scoped executor copies and preserved across thread continuations.
- Model reporting and replay logs use the unified upstream format.
- The fork maintenance direction is now documented: same-problem conflicts prefer upstream, fork-only deltas stay only for uncovered behavior.

## Fixed

- Unknown encrypted content is preserved in OpenAI responses compatibility mode.
- Gemini schema nodes with properties enforce object type; document blocks are supported in Claude request translation.
- Truncated streams missing `finish_reason` now report an error instead of silently ending.
- Missing Claude thread-state errors are marked for client replay; cache breakpoints are reserved for thread continuation; system messages stay top level for terminal user turns.
- Model version parsing for assistant prefill rejection is refined.
- Reasoning effort is recorded from finalized upstream payloads after caching.
- Antigravity probes are coalesced with plugin model ownership respected; model lifecycle and cooldown state are preserved.
- Auth mutation locking with persistence delta merging prevents unsafe concurrent updates; terminal unauthorized state blocks refresh retry.
- Context-hash rejection logging with batch retry logic improves Antigravity failure diagnosis.
