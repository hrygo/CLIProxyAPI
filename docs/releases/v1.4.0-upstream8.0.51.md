# v1.4.0-upstream8.0.51 - 2026-11-05

## Summary

- Replays the complete upstream v8.0.51 tree (207 non-merge upstream commits since v8.0.35) onto `main` while keeping every fork capability: strict Codex tool-argument canonicalization, the responses-tools pipeline with `local-refs: "flatten"`, the Gemini/Vertex/AI Studio streaming repairs and the opt-in `requests.streaming.bootstrap-timeout`.
- Adds structured usage accounting across providers, Vertex per-model routing, plugin-host extensions, Home cluster latency telemetry and Codex traffic compression.
- Compatibility: no configuration or credential migration is required. Existing `config.yaml`, `auths/` and the LaunchAgent keep working; the upgrade replaces the binary only.

## Upstream alignment

- Upstream release: `v8.0.51`
- Previous baseline: `v8.0.35`
- Intake record: [absorbed.md](../../ops/upstream-intake/absorbed.md)
- Ported: 207 non-merge upstream commits (31 features, 134 fixes) from `v8.0.35` to `v8.0.51`, replayed as the complete release tree and merged through PR #41 at `69a96b0d`.
- Skipped: Upstream-only CI workflows (`docker-image`, `auto-retarget-main-pr-to-dev`, `agents-md-guard`, `pr-path-guard`), `FUNDING.yml`, promotional assets and the network model-catalog refresh script stay out per fork policy; no upstream runtime behavior is excluded.

## Breaking changes

- None. Request and response contracts, configuration keys and credential formats keep their previous meaning.

## Added

- Structured token accounting for Google (Gemini, Vertex, AI Studio, Antigravity), Anthropic Messages, OpenAI/Codex and xAI, including cached and reasoning tokens where the provider reports them.
- Vertex per-model and per-credential `openapi` routing settings, plus conversion of streaming `functionCall` partial arguments.
- Plugin host additions: multi-provider model registration, multiple OAuth login entries, raw request-body patching and retry-after metadata from plugin executor errors.
- Home cluster latency telemetry and planned rebalance handoff.
- Codex full-chain compression and opt-in visible Codex commentary with preserved replay.
- Management API additions: SIWC credential status, session-scoped OAuth proxying and on-demand model-catalog refresh.

## Changed

- Upstream-only maintenance workflows are replaced by the fork's `pr-test-build` and `release` workflows, both pinned to Go `1.26.10`.
- The accepted baseline registry now records `v8.0.51` as a complete-tree replay, and the release guard verifies that record.
- Custom plugins can adopt RPC schema versions 7-10; plugins built for schema 6 keep working through the host's compatibility branches.

## Fixed

- Truncated HTTP 200 streams from Gemini no longer put the credential into cooldown or trigger failover.
- SSE framing recovery, Claude Code recovery guidance after a failed automatic credential renewal, and Codex SIWC credential enforcement.
- Request-log filenames reject path traversal, and the Home RESP control channel validates message bounds and recovers from connection panics.

## Security

- Upstream hardening included: request-log filename path traversal prevention, RESP protocol bounds validation and panic recovery. No fork-specific security change.

## Validation

- Full intake gate PASS on integration commit `2c5a3b3b` with Go 1.26.10: maintenance tooling (75 tests), gofmt, `go vet ./...`, responses-tools invariants, `go test ./... -count=1`, seven race-sensitive packages and the server build.
- Both integration PRs (#41 and #42) passed the `build` check, and the tested merge tree equals candidate tree `82c21b74`.
- Fork capabilities were verified item by item (F01-F14) in [the replay record](../../ops/upstream-intake/reviews/v8.0.51-replay-spike.md).
- Coverage limit: provider and WebSocket evidence uses isolated local fixtures; no live provider or real client replay was performed.

## Known issues

- Gemini prompt completion: usage or continuation signatures that arrive after a terminal are not awaited and can be lost. This is an accepted tradeoff, not a regression.
- Upstream defects retained unchanged: Antigravity orphaned thought signatures, AI Studio `event: error` frames without data, `error` plus `[DONE]` treated as completion, empty-argument function calls in OpenAI-compatible streams, invalid `apply_patch` arguments recorded as zero usage, and unknown Devin protobuf fields rejected with 422.
